Welcome to prometeo's documentation!
====================================
This is prometeo, an experimental modeling tool for embedded high-performance computing. prometeo provides a domain specific language (DSL) based on a subset of the Python language that allows one to conveniently write scientific computing programs in a high-level language (Python itself) that can be transpiled to high-performance self-contained C code easily deployable on embedded devices.

The same program runs in the Python interpreter, where it can be debugged,
checked and plotted with the whole Python ecosystem, and as transpiled C,
which computes the same numbers with static memory and no Python runtime.

features
--------

1. **Python compatible syntax:** prometeo is a DSL embedded into the Python language. prometeo programs run in the Python interpreter, where they can be debugged with pdb and combined with any Python code (NumPy, SciPy, matplotlib, CasADi, ...) that is removed when transpiling.
2. **NumPy-like linear algebra:** matrix and vector expressions such as ``P = Q + A.T @ P @ A - K.T @ R @ K``, ``K[0:n, n:] = B.T``, ``y = A @ x + B @ u`` or ``c : float = x @ Q @ x``, with ``cholesky`` and ``cho_solve``, are lowered to BLASFEO calls, with temporaries allocated statically.
3. **checked:** a static checker accepts exactly the subset of Python described in :doc:`the language reference <language/language>` and rejects everything else with an error pointing to the source, before running or transpiling. Types and matrix sizes are checked at compile time (and at run time when they are not known).
4. **efficient:** prometeo programs transpile to C code that calls BLASFEO, with performance comparable to hand-written code using it.
5. **deterministic memory usage:** prometeo computes a bound on the memory used by a program, and transpiled programs allocate it once: there is no dynamic memory allocation and no garbage collection.
6. **self-contained and embeddable:** transpiled programs are C99 code that depends only on BLASFEO and a small runtime, not on the Python runtime library.
7. **CasADi:** models and their derivatives defined with `CasADi <https://web.casadi.org>`__ are called from prometeo code, through C code generated by CasADi.

The `examples <https://github.com/zanellia/prometeo/tree/master/examples>`__ include a
`minimal example <https://github.com/zanellia/prometeo/blob/master/examples/minimal/minimal.py>`__
showing the syntax, and an
`example of the Python workflow <https://github.com/zanellia/prometeo/tree/master/examples/python_workflow>`__
(checks, plots and debugging in Python, then transpiling).
