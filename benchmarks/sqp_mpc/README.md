# SQP for MPC: prometeo vs acados

The optimal control problem of [`examples/sqp_mpc`](../../examples/sqp_mpc/sqp_mpc.py)
(cart-pole, N = 20, input bounds), solved with:

- **prometeo**: the example, transpiled to C. Gauss-Newton SQP; QPs solved by
  a primal-dual interior-point method (Mehrotra's predictor-corrector) written
  in prometeo, whose Newton steps are Riccati recursions; RK4 step and
  Jacobians generated by CasADi.
- **acados**: the same problem (one RK4 step per interval, Gauss-Newton,
  `PARTIAL_CONDENSING_HPIPM` with `qp_solver_cond_N = N`, i.e. no condensing),
  [`acados_sqp.py`](acados_sqp.py).

Both give the same solution (to 5e-11, also in closed loop), which matches
CasADi/IPOPT (`tests/test_sqp_reference.py`).

## Results

Intel i7-1370P, gcc 11.4, `-O2`; times measured by each program (prometeo:
`main` without setup; acados: `time_tot`), best of several runs.

|                                    | acados (HPIPM)       | prometeo, BLASFEO `GENERIC` | prometeo, BLASFEO `X64_INTEL_HASWELL` |
|------------------------------------|----------------------|-----------------------------|---------------------------------------|
| full SQP solve (13 SQP iterations) | 1.8 - 2.7 ms         | 4.0 - 4.3 ms                | 3.6 ms                                |
| QP iterations in the solve         | 56                   | 78                          | 78                                    |
| RTI step (average of 30)           | 180 us               | 320 - 330 us                | 275 us                                |

acados uses BLASFEO built for `X64_AUTOMATIC` (AVX2 on this CPU). The
remaining difference is mostly overhead of many small BLASFEO calls (the
matrices are at most 5x5): HPIPM uses fused routines and a structure tuned for
this case, while the prometeo solver is a direct transcription of the
algorithm. For reference, before the interior-point method used Mehrotra's
predictor-corrector, the starting point was improved and the generated code
and runtime were compiled with `-O2`, the prometeo solve took 8 ms.

## Running

```
benchmarks/sqp_mpc/time_prometeo.sh [python]
```

and, with acados installed (`ACADOS_SOURCE_DIR` set, `acados_template`
installed), from a scratch directory (acados generates code there):

```
python <prometeo>/benchmarks/sqp_mpc/acados_sqp.py [repetitions]
```
